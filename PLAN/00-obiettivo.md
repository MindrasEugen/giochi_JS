# Obiettivo

Ultima modifica: 2026-11-03

**Giochi JS** — raccolta di 5 giochi da browser in HTML, CSS e JavaScript senza framework (impiccato, indovina il numero, sasso carta forbici, sette e mezzo, tris).

Obiettivo di questo lavoro: correggere i bug trovati nell'audit, unire i giochi in una pagina home, migliorare il CSS di tutti i giochi e dare al Tris un menu di difficoltà con una modalità "impossibile" basata sull'algoritmo minimax.
