Solitari / Golf

Una in più, una in meno.

Svuota le sette colonne portando sulla base carte di un valore sopra o sotto. Meno carte restano, meglio è.

Tempo0:00
Mosse0

Regole
  1. Sette colonne di cinque carte scoperte; una carta va sulla base e le altre sedici formano il mazzo.
  2. Si porta sulla base la carta in cima a una colonna se vale una in più o una in meno di quella sulla base, di qualunque seme. Non si gira: niente asso sul re né re sull’asso.
  3. Basta un tocco su una carta per mandarla sulla base. Quando non ci sono mosse tocca il mazzo per girare una nuova carta sulla base.
  4. Si vince svuotando tutte le colonne; altrimenti il punteggio è il numero di carte rimaste (meno sono, meglio è).
  5. Come si gioca: trascina le carte con il mouse o con il dito, oppure tocca una carta e poi la pila dove vuoi metterla. Due tocchi (o doppio clic) mandano la carta alla base. Annulla torna indietro di una mossa (anche più volte).
